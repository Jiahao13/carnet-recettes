Q1. Chaque commit est signé avec le nom et l'e-mail de user.name / user.email.
GitHub relie un commit à un compte en comparant cet e-mail avec ceux du compte.
Si l'adresse est différente, le commit s'affiche sans photo de profil ni lien
vers mon compte, avec un auteur "inconnu", et il ne compte pas dans mon
graphique de contributions.

Q2. GitHub n'accepte plus le mot de passe dans le terminal. Un jeton est plus
sûr : il ne donne que les droits cochés (ici "repo"), on peut le révoquer sans
changer son mot de passe, et s'il fuite, le compte reste protégé.
Avec une date d'expiration, un jeton oublié ou volé devient inutilisable tout
seul, ce qui limite les dégâts.

Q3. (a) Vrai : un commit est enregistré dans le dépôt local (.git), il n'a
pas besoin d'internet.
(b) Faux : Git est un logiciel local, un compte GitHub n'est utile que pour
héberger et partager.
(c) Faux : un commit reste chez moi tant que je ne fais pas git push.
(d) Vrai : une équipe peut utiliser GitLab, Bitbucket ou un serveur à elle.
(e) Vrai : Git est installé sur la machine, GitHub est un site web qui
héberge des dépôts Git.
